# SELLIX FF Store

## GitHub Pages par chalane ke steps
1. GitHub par naya repository banao (jaise `sellix-ff`), Public rakho.
2. Is folder ki saari files upload karo (index.html, style.css, script.js, items.json, admin.html, images folder).
3. Repository > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/sellix-ff/

## Naya item kaise list karo
1. Apni site par /admin.html kholo (jaise .../sellix-ff/admin.html).
2. Title, price, details bharo, photos chuno, "Code banao" dabao.
3. Photos `images` folder me upload karo (wahi file naam).
4. `items.json` edit karke wo code paste karo. Commit karte hi item sabko dikhega.

## Item hatane ke liye
items.json me us item ka poora block delete karo.
